# PureNote

Release artifacts for PureNote, a handwriting-first note taking app for Windows.

The app updates itself from the assets on the [latest release](https://github.com/MaykEu/PureNote/releases/latest):

- `latest.json` is the update manifest the app reads.
- `PureNote_<version>_x64-setup.exe` is the installer, signed with the release key the app verifies.
